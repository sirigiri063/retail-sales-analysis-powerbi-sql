# Project Structure

```
retail-sales-analysis-powerbi-sql/
│

│
├── 📂 sql/
│   └── Retail_Customer_Insights.sql          # Annotated SQL queries (5 sections)
│
├── 📂 reports/
│   └── Retail_Sales_Analysis.pbix            # Power BI interactive dashboard
│
├── 📂 docs/

│
├── 📂 assets/
```

## Folder Descriptions

| Folder | Contents | Purpose |
|--------|----------|---------|
| `data/` | `retail_sales_2_edited.csv` | Cleaned source data — import into SQL or connect via Power BI |
| `sql/` | `Retail_Customer_Insights.sql` | All business analysis queries, organized in 5 labeled sections |
| `reports/` | `Retail_Sales_Analysis.pbix` | The Power BI dashboard — open with Power BI Desktop |
| `docs/` | `STRUCTURE.md` | Project structure documentation |
| `assets/` | Dashboard screenshots | Preview images used in the README |
